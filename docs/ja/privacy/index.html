Annex プライバシーポリシー

最終更新: 2026年10月12日

Annex は、Classroom Adventure が作る Android アプリと Mac アプリです。このポリシーでは、あなたの情報をどう扱うかを説明します。

集める情報

個人情報は一切集めません。Annex にはアカウント・分析ツール・広告がなく、私たちのサーバーもありません。

画面と操作の送り方

Mac アプリは拡張ディスプレイの映像を、USB ケーブルか手元の Wi-Fi で Android 端末へ直接送ります。タッチやペンの操作も同じ経路で戻ります。インターネットや私たちを経由することはありません。

端末に保存する情報

Android アプリはランダムな端末 ID を作り、端末内に保存します。Mac でその端末を許可すると、Mac アプリがその ID と端末名を保存し、次からは確認しません。Android アプリの設定の「Mac にもう一度許可を求める」や、Mac アプリのメニューの「許可した端末を削除」で、いつでも消せます。

画面の大きさやフレームレートなどの設定は、端末内にだけ保存します。

使う権限

Android では、Mac を見つけて映像を受け取るためにネットワークを使います。Mac では、画面収録は Annex 自身の拡張ディスプレイを取り込むためだけに、アクセシビリティはタッチ操作をカーソルの動きに変えるためだけに使います。
